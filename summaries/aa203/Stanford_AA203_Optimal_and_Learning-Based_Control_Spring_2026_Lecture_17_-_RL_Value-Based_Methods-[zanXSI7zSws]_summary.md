### 1. Executive Summary & Core Concepts

**Lecture Overview:**
This lecture marks the transition from theoretical foundations to specific algorithmic implementations within **model-free reinforcement learning**. We move beyond exact dynamic programming methods (which require known system dynamics) to sampling-based methods like Monte Carlo and Temporal Difference (TD) learning. The core objective is to introduce **SARSA** (an on-policy algorithm) and **Q-Learning** (an off-policy algorithm), explaining how they utilize TD updates to solve control problems. Finally, we address the scalability bottleneck of tabular methods by introducing **Value Function Approximation** and **Deep Reinforcement Learning (DQN)**, detailing critical stabilization techniques like experience replay and fixed targets.

**Key Concepts Highlight:**
*   **Value-Based Methods:** A category of model-free RL algorithms where the agent learns an estimate of the value function (or Q-function) to derive a policy. The policy is derived by selecting the action that maximizes this value.
*   **Temporal Difference (TD) Learning:** A learning paradigm that updates value estimates using a "one-step look-ahead" target (current reward + discounted future value estimate) rather than waiting for a full episode to end. It is a lower-variance estimator compared to Monte Carlo and allows for online updates.
*   **SARSA (On-Policy):** The first major TD-based control algorithm. It is "on-policy" because the policy used to generate data (behavior policy, $\mu$) and the policy being evaluated/improved (target policy, $\pi$) are the same (typically $\epsilon$-greedy). The name comes from the five elements defining its update: **S**tate, **A**ction, **R**eward, **S**tate (next), **A**ction (next).
*   **Q-Learning (Off-Policy):** An algorithm that decouples the behavior policy from the target policy. It uses an $\epsilon$-greedy behavior policy to explore the environment but updates the Q-function based on the greedy (optimal) policy. This allows it to converge to the optimal policy even if exploration is random.
*   **On-Policy vs. Off-Policy:** A fundamental distinction. **On-policy** methods evaluate/improve the policy currently interacting with the environment. **Off-policy** methods evaluate a different target policy using data generated by a behavior policy. This allows for learning from past data or human demonstrations.
*   **Value Function Approximation (VFA):** Replacing discrete lookup tables (which fail in high-dimensional spaces) with parametric functions (e.g., neural networks) to represent value functions. This addresses memory constraints and generalization across states.
*   **Deep Q-Networks (DQN):** A deep RL architecture that uses Convolutional Neural Networks (CNNs) to approximate the Q-function directly from pixel inputs. It introduces **Experience Replay** (to decorrelate data) and **Fixed Targets** (to stabilize regression) to make training stable.

### 2. Deep Dive: Expanded Lecture Notes (The "Teaching" Section)

#### Concept 1: From Monte Carlo to Temporal Difference (TD)
*   **Detailed Explanation:**
    *   **Monte Carlo (MC)** learns by sampling complete episodes until a terminal state is reached. The target is the total return ($G_t$) observed over that entire rollout.
    *   **TD Learning** borrows the "bootstrapping" idea from Dynamic Programming. Instead of waiting for the episode to end, it updates the value estimate using a one-step target: $r_t + \gamma v(x_{t+1})$.
    *   **Why TD is superior for control:**
        1.  **Lower Variance:** MC accumulates stochasticity over the entire episode. TD only samples one step, reducing variance.
        2.  **Online Updates:** TD updates occur at every time step, allowing the agent to learn from incomplete sequences. MC requires a full episode to compute a single update.
        3.  **Loop Handling:** If an agent gets stuck in a policy loop, MC will never update values (since it never reaches a terminal state). TD will continuously update values, eventually assigning negative values to the loop due to accumulating negative rewards, allowing the agent to escape.
*   **Context & Nuance:** In the "Windy Grid World" example, SARSA (using TD) successfully learned to navigate the wind, whereas MC might struggle if the agent gets stuck in a suboptimal loop before reaching the goal.
*   **Analogy:** Think of MC as a historian who only writes a book after a person’s entire life is over. TD is like a journalist updating a live blog post after every single event, adjusting the narrative in real-time based on immediate feedback.
*   **Key Takeaway:** TD learning is preferred for control because it is more efficient, lower variance, and capable of online learning without requiring terminal states.

#### Concept 2: SARSA and the "Quintuple"
*   **Detailed Explanation:** SARSA is the first algorithm to combine TD updates with a control framework. To perform a Q-function update, we need five specific elements:
    1.  Current State ($S_t$)
    2.  Current Action ($A_t$)
    3.  Reward ($R_t$)
    4.  Next State ($S_{t+1}$)
    5.  Next Action ($A_{t+1}$)
    *   The update rule is: $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha [R_t + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t)]$.
    *   Crucially, $A_{t+1}$ is sampled from the **same** $\epsilon$-greedy policy used to act in the environment.
*   **Context & Nuance:** Because the next action is part of the update, SARSA learns the value of the *actual* policy it is executing. If the policy is exploratory ($\epsilon$-greedy), the Q-values reflect that exploration.
*   **Analogy:** Imagine a taxi driver learning to drive. SARSA is like a driver who, after every turn, immediately grades that turn based on *exactly* what they did next. If they made a random turn (exploration), they grade that specific random turn.
*   **Key Takeaway:** SARSA is an **on-policy** algorithm because it evaluates the policy it is currently using to interact with the environment.

#### Concept 3: Q-Learning and Off-Policy Logic
*   **Detailed Explanation:** Q-Learning modifies SARSA’s update rule. Instead of using the action actually taken next ($A_{t+1}$), it uses the **greedy** action relative to the Q-function: $\max_a Q(S_{t+1}, a)$.
    *   **Behavior Policy ($\mu$):** $\epsilon$-greedy (exploratory).
    *   **Target Policy ($\pi$):** Greedy (exploitative).
    *   **Update Rule:** $Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha [R_t + \gamma \max_a Q(S_{t+1}, a) - Q(S_t, A_t)]$.
*   **Context & Nuance:** In the "Cliff World" example, SARSA learned a safe path (staying away from cliffs) because it accounted for the risk of its own random exploration. Q-Learning learned the *shortest* path (closest to the cliff) because it assumes the agent will eventually act greedily (perfectly). During training, Q-Learning suffers higher reward losses (falling in cliffs) because it is exploring randomly, but the *converged* policy is optimal.
*   **Analogy:** Q-Learning is like a strategist who plans the perfect route based on "if I were perfect, I would take this path." It ignores the fact that the driver is currently a novice making mistakes.
*   **Key Takeaway:** Q-Learning is **off-policy** because it learns the value of the *optimal* policy using data generated by a *different* (exploratory) policy.

#### Concept 4: On-Policy vs. Off-Policy Definitions
*   **Detailed Explanation:**
    *   **On-Policy:** The data used for updates is generated by the same policy currently being evaluated. (SARSA).
    *   **Off-Policy:** The data used for updates is generated by a behavior policy $\mu$, but we are estimating the value of a target policy $\pi$ ($\pi \neq \mu$).
*   **Why Off-Policy Matters:**
    1.  **Efficiency:** We can reuse old data or learn from human demonstrations without needing to interact with the environment ourselves.
    2.  **Separation of Concerns:** We can decouple *exploration* (needing to be random to learn) from *exploitation* (needing to be greedy to win).
*   **Context & Nuance:** Off-policy learning allows us to throw away the "exploration noise" in the final policy evaluation, leading to potentially better final performance, though training dynamics may look worse initially.
*   **Key Takeaway:** Off-policy learning allows us to learn about a perfect policy using imperfect, exploratory data.

#### Concept 5: Value Function Approximation (VFA)
*   **Detailed Explanation:** Tabular methods (lookup tables) fail in high-dimensional spaces (e.g., Go, Atari) due to:
    1.  **Memory:** Storing values for $10^{170}$ states is impossible.
    2.  **Covariance of Dimensionality:** You must visit every state to update it.
    *   **Solution:** Use a parametric function $V(x, \theta)$ or $Q(x, u, \theta)$.
    *   **Mechanism:** Treat RL as a regression problem. We minimize the error between the predicted value and the TD/MC target. We update parameters $\theta$ using gradient descent.
*   **Context & Nuance:** This allows **generalization**. If the agent sees a state similar to a previous one, the neural network can interpolate values, whereas a lookup table would have no entry for the new state.
*   **Analogy:** A lookup table is like a phone book (exact match required). A neural network is like a search engine (returns relevant results even if the query isn't an exact match).
*   **Key Takeaway:** VFA allows RL to scale to complex environments by compressing value information into a small set of parameters.

#### Concept 6: Deep Q-Networks (DQN) & Stabilization
*   **Detailed Explanation:** DQN applies Q-Learning to high-dimensional inputs (pixels) using a CNN. Two major instability issues arise:
    1.  **Correlated Data:** Consecutive frames in a game are highly correlated, violating the IID assumption of regression.
    2.  **Moving Target:** The target value depends on the current Q-network, which is changing while we try to fit to it.
    *   **Solution 1: Experience Replay:** Store transitions in a buffer. Sample random batches from this buffer to update the network. This decorrelates the data.
    *   **Solution 2: Fixed Targets:** Use two networks: a "current" network ($\theta$) and a "target" network ($\phi$). The target network is frozen for a period, providing a stable regression target. Periodically, $\phi$ is updated to match $\theta$ (or via Polyak averaging).
*   **Context & Nuance:** These tricks were groundbreaking in 2014, allowing RL to solve Atari games directly from pixels.
*   **Key Takeaway:** DQN succeeds because it stabilizes the non-stationary regression problem inherent in deep RL through replay buffers and target networks.

**Answer Key & Explanations**

**1. Fundamental Difference in Targets:**
*   **Monte Carlo:** The target is the total return ($G_t$) accumulated over the entire episode until termination.
*   **TD:** The target is a one-step estimate: $r_t + \gamma v(s_{t+1})$. It uses the current value estimate of the next state rather than waiting for the episode to end.

**2. SARSA Quintuple:**
*   The five elements are: Current State ($S_t$), Current Action ($A_t$), Reward ($R_t$), Next State ($S_{t+1}$), and **Next Action** ($A_{t+1}$). The inclusion of the next action is what distinguishes SARSA from Q-Learning.

**3. Tabular Failures:**
*   **Memory:** Storing a value for every state-action pair requires immense memory in high-dimensional spaces.
*   **Generalization/Covariance:** Tabular methods cannot generalize; a state not explicitly visited has no value entry. VFA solves this by using parameters to generalize across similar states.

**4. Purpose of Experience Replay:**
*   To decorrelate the training data. In RL, consecutive transitions are highly correlated (violating IID assumptions). By storing transitions in a buffer and sampling randomly, we reduce correlation, stabilizing the regression process.

**5. Behavior vs. Target Policy:**
*   **Behavior Policy ($\mu$):** The policy used to interact with the environment and generate data (usually exploratory, e.g., $\epsilon$-greedy).
*   **Target Policy ($\pi$):** The policy whose value we are estimating or improving (usually exploitative, e.g., greedy). In off-policy learning, $\mu \neq \pi$.

**6. SARSA vs. Q-Learning in Cliff World:**
*   SARSA is **on-policy**. It learns the value of the $\epsilon$-greedy policy. Because it knows it *might* take a random step into the cliff, it assigns lower value to states near the cliff, resulting in a "safer" detour path. Q-Learning is **off-policy**; it assumes the agent will act greedily (perfectly) in the future, ignoring the risk of random exploration, so it learns the shortest path closest to the cliff.

**7. Handling Infinite Loops:**
*   **Monte Carlo:** If the agent never reaches a terminal state, MC never computes a return, so it **never updates** the Q-function. It gets stuck.
*   **TD:** TD updates at every step. Even in a loop, the agent accumulates negative rewards (assuming a cost per step). Over time, the Q-values for the loop states decrease, eventually making the loop suboptimal compared to other actions.

**8. Continuous Control:**
*   Standard Q-Learning requires a discrete set of actions to take the $\max$. For continuous actions, calculating $\max$ is an optimization problem, not a simple lookup.
*   **Modification:** You would need to move away from tabular Q-Learning to methods like **Policy Gradient** methods or use approximation techniques that handle continuous outputs (like DDPG/SAC), rather than a simple lookup table over discrete actions.

**9. DQN Target Instability:**
*   If we use the current network parameters to calculate the target, the target changes every time we update the network, creating a "moving target" that is hard to regress against.
*   **Fixed Target Network:** We use a second network ($\phi$) that is frozen for a period. This provides a stable target. We periodically copy the current network ($\theta$) to the target network ($\phi$) (or use Polyak averaging) to slowly update the target.

**10. Training Dynamics in Windy Grid:**
*   Q-Learning uses an $\epsilon$-greedy behavior policy. During training, it randomly explores and may fall into cliffs (large negative reward). SARSA, learning the value of the exploratory policy, avoids the cliff more consistently during training. Thus, Q-Learning has a lower sum of rewards *during training* because it takes more risks, but its *final converged policy* is optimal.

**11. Critique of "Off-Policy is Always Superior":**
*   **Argument For:** It allows learning from past data or human demos and decouples exploration from the final policy.
*   **Argument Against (Critique):** Off-policy can be less stable. As seen in the cliff example, the training trajectory can be worse (more failures) because it doesn't account for the exploration noise. On-policy (SARSA) is safer for the specific policy being executed. "Superior" depends on whether you prioritize the safety of the current agent (On-policy) or the optimality of the final model (Off-policy).

**12. IID Assumption Violation:**
*   Standard regression assumes data is independent. In RL, data is sequential and correlated (frame $t$ depends on frame $t-1$).
*   **Mitigation:** DQN uses **Experience Replay** to break this correlation by sampling from a history of states. It also uses **Fixed Targets** to handle the non-stationarity of the target values.

**13. Deployment Risks:**
*   **SARSA:** We are concerned because SARSA's policy *is* the $\epsilon$-greedy policy. If we deploy it, it will continue to make random errors ($\epsilon$) forever, which is dangerous for robots. We would need to decay $\epsilon$ to 0.
*   **Q-Learning:** We are less concerned about the *deployed* policy because Q-Learning converges to the *greedy* policy. We can set $\epsilon=0$ at deployment, and the robot will follow the optimal path. The risk is only during the *training* phase.
